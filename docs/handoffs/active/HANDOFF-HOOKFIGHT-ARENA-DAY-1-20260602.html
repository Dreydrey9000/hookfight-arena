Key Decisions

• Convex Auth instead of Clerk
↳ Drey doesn't use Clerk; Convex Auth is the stack standard, built-in, no third-party auth service. Auth wasn't wired yet so it was a clean swap.
• runAI() stub-mode when AI_API_KEY unset
↳ Lets the entire free loop be built + demoed before any key exists; flip key on and the real model takes over with zero code change.
• Bracket as a pure function (no AI, no DB)
↳ Makes it the one piece I could actually unit-test (6/6), and keeps AI cost at $0 for the tournament step.
• No @vercel/og dependency
↳ Next 16 ships next/og built in.
• Pinned Turbopack root in next.config.ts
↳ A stray ~/package-lock.json was hijacking Next's inferred workspace root.
